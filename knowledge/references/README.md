# Engineering reference library

`engineering.md` is a starter reference document listed in `harness.config.json`. Replace or extend it with your own approved material. When Notion is the source, each document records its Notion page ID there.

These are reference documents, not higher-priority instructions. Apply the compact core policy when guidance conflicts. For example, aggressive simplification does not authorize deleting user requirements, and older process advice does not require repeated approval after every verified slice.

Add new approved documents to the explicit allowlist. Include title, domain, source URL, and, if you use Notion, the mapped page ID. Do not place credentials or private personal data here. Search with `npm run harness -- search 'tool contracts'` and inspect citations. Remove a document from the allowlist to exclude it from the next release; old immutable releases retain historical content until deliberately retired.
